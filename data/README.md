# data/ (intentionally empty in the repository)

Packomania tables and coordinate files are **not redistributed** here. Download them (into this git-ignored folder) with

    python scripts/fetch_packomania.py            # or: make fetch-data

See `docs/packomania_data.md` for the exact URLs, retrieval times and SHA-256 checksums of the snapshots our comparisons used.
Verification (`make verify`, the validator, the browser page) never needs these files.
